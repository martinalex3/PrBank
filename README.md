### 📝 Descripción del Proyecto
**PrBank** es una aplicación web diseñada para modernizar la interacción entre el usuario y sus finanzas personales. Su propósito es facilitar tareas complejas como el seguimiento de movimientos financieros y la creación de cuentas de crédito mediante una interfaz limpia y accesible. 

El proyecto destaca por su **diseño responsivo**, utilizando técnicas modernas de maquetación para garantizar que la banca sea accesible tanto en ordenadores de escritorio como en dispositivos móviles.

### 🏗️ Arquitectura y Estructura
El proyecto sigue el principio de **separación de responsabilidades** (Separation of Concerns), dividiendo claramente el código para facilitar su mantenimiento:

* **HTML (Estructura):** Uso de marcado semántico para definir el contenido de forma lógica y accesible.
* **CSS (Presentación):** Centralizado en un archivo `styles.css` utilizando **Flexbox** para crear layouts flexibles y adaptables. Se emplean variables globales (`:root`) para mantener una identidad visual coherente.
* **JavaScript (Lógica):** Los scripts se organizan de forma independiente para manejar la interactividad, validaciones de seguridad y peticiones asíncronas (`fetch`) a la API del servidor.

### 📊 Estado del Proyecto
El proyecto se encuentra actualmente **terminado y funcional**.
* **Completado:** Interfaz de usuario (UI), lógica de navegación y gestión de sesiones.
* **Completado:** Integración de videoteca de ayuda y tutoriales H5P.
* **Completado:** Optimización de accesibilidad en botones y navegación mediante el lector de pantalla **Orca**.

### 📽️ Demostración de funciones y aplicaciones
* **Layout Adaptable:** Gracias al uso de **Flexbox**, las tarjetas de cuentas y formularios se reubican automáticamente según el tamaño de la pantalla.
* **Gestión de Cuentas:** Alta de cuentas de ahorro y crédito con saldos en tiempo real.
* **Seguridad Avanzada:** Módulo de cambio de contraseña con validación de complejidad.
* **Tutoriales Interactivos:** Capas overlay para guiar al usuario sin abandonar la página principal.

### 🔓 Acceso al Proyecto
1. **Clona este repositorio:** `git clone https://github.com/tu-usuario/PrBank.git`
2. **Navegador:** Abre `index.html`. Se recomienda usar un servidor local para habilitar las funcionalidades de la API.

### 🛠️ Tecnologías utilizadas
* **Frontend:** HTML5 Semántico, CSS3 (Flexbox & Variables), JavaScript Vanilla.
* **Integración:** AJAX/Fetch API para consumo de servicios REST (JSON).
* **Multimedia:** Integración de H5P Player.
